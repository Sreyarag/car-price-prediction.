# Used Car Price Prediction 🚗

## Project Overview

This project uses Machine Learning to predict the selling price of used cars using Linear Regression.

The dataset was obtained from Kaggle and contains information about used cars, including manufacturing year, kilometres driven, fuel type, seller type, transmission, and ownership history.

## Objectives

* Explore and understand the dataset using Exploratory Data Analysis (EDA).
* Clean and prepare the data for Machine Learning.
* Train a Linear Regression model.
* Evaluate model performance using regression metrics.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## Machine Learning Workflow

1. Data loading and inspection
2. Exploratory Data Analysis
3. Feature selection and preprocessing
4. Train-test split
5. Linear Regression model training
6. Model evaluation and visualization

## Model Evaluation

Initial model results:

* MAE: 221203.46
* RMSE: 426356.03
* R² Score: 0.4043

These results represent a baseline model. Further feature engineering and experimentation may improve performance.

## How to Run

1. Download or clone this repository.
2. Install the required Python libraries.
3. Open `car_price_prediction.ipynb` in Google Colab or Jupyter Notebook.
4. Upload the Kaggle CSV dataset when prompted.
5. Run the notebook cells in order.
